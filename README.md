# StocksReport

A **100% free** stock analysis pipeline. Give it any US-listed ticker and it:

1. **Retrieves** price history, financial statements, analyst ratings/targets and news (Yahoo Finance via `yfinance`).
2. **Verifies** the retrieved numbers against primary sources — **SEC EDGAR filings** (XBRL) and an independent **Nasdaq** price feed — and corrects them where Yahoo's data is wrong or incomplete.
3. **Analyses** the company: valuation, growth, profitability, financial health, momentum and analyst consensus, benchmarked against the **S&P 500 (SPY)**, the **sector ETF** and **sector peers**.
4. **Writes** pros & cons, a retail-investor view, a portfolio-manager view, risks/catalysts and a **Buy / Hold / Sell** verdict with a fair-value estimate and entry price.
5. **Outputs** an HTML report, Excel workbook, PowerPoint deck, or an interactive Streamlit web app.

No paid APIs, no API keys, no LLM credits. All text is generated by transparent rules from the data, and every
pro/con cites the metric behind it.

> ⚠️ Educational tool, not financial advice.

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export SEC_USER_AGENT="Your Name your@email.com"   # SEC asks for a contact in the User-Agent
```

```bash
python cli.py AAPL                                   # HTML report in reports/
python cli.py AAPL MSFT JPM --format html xlsx pptx  # all formats + Excel comparison sheet
python cli.py NVDA --peers AMD AVGO INTC QCOM        # custom peer group
python cli.py verify AAPL MSFT JPM XOM JNJ AMZN      # data-accuracy reconciliation report
streamlit run app.py                                 # web app
```

## How the verdict is made

| Pillar (weight) | Inputs |
|---|---|
| Valuation (25%) | forward P/E vs peer median, PEG, free-cash-flow yield |
| Growth (20%) | revenue and diluted-EPS growth, last fiscal year |
| Profitability (20%) | net margin (absolute and vs peers), return on equity |
| Financial health (10%) | debt/equity, FCF sign (banks: ROE proxy, D/E not meaningful) |
| Momentum (10%) | 1-year total return vs S&P 500, price vs 200-day average |
| Analyst consensus (15%) | upside to mean target, average rating |

Each sub-metric maps linearly to 0–100 between a "bad" and "good" anchor; missing pillars are dropped and weights
renormalised. **Buy ≥ 65, Sell < 45, otherwise Hold.** Fair value = ⅔ analyst mean target + ⅓ (peer-median
forward P/E × forward EPS), the latter only when ≥ 3 peers have valid data. Entry price = fair value − 10% margin
of safety.

Investor sentiment comes from the analyst rating mix and its 3-month trend, upgrades/downgrades in the last 90
days, and news headlines scored with VADER plus a finance lexicon (offline, free).

## Data verification

`stocksreport/verify` reconciles every report's inputs:

| Category | Source of truth | Tolerance |
|---|---|---|
| SEC filing | SEC EDGAR XBRL (10-K / 10-Q): revenue, net income, diluted EPS, gross & operating income, diluted shares, operating cash flow, assets, liabilities, equity, shares outstanding | PASS ≤ 0.5% (EPS to the cent), WARN ≤ 2%, FAIL above |
| Price | Nasdaq end-of-day closes, last 250 sessions | every session within 0.5% |
| Derived ratio | Yahoo's pre-computed ratios vs ours | PASS ≤ 1–5%, WARN ≤ 25% (definitions differ) |
| Internal consistency | Assets = Liabilities + Equity; 4 quarters sum to the annual figure | ≤ 0.1% / 0.5% |

Where Yahoo's data is incomplete or conflicts with a filing, the pipeline uses the SEC value and lists the
correction in the report ("Corrections applied").

### Findings on real data (Nov 2026, 6-stock cross-sector basket)

* **Prices:** 1,500 daily closes checked (AAPL, MSFT, JPM, XOM, JNJ, AMZN) — all match Nasdaq to the cent.
* **Filed fundamentals:** every SEC-matched value for AAPL, MSFT and JNJ matches the filings exactly.
* **Issues found in Yahoo's data and how they are handled:**
  * *AMZN* — Yahoo returned an all-blank quarter (Q2 2026), which would have made TTM net income $77.7B instead
    of $134.8B. TTM is now rebuilt from SEC 10-Q/10-K figures.
  * *JPM FY2024 revenue* — Yahoo $169.4B vs 10-K net revenue $177.6B (−4.6%; ≈ the one-off Visa share-exchange
    gain). Revenue growth is recomputed from filed values (2.8% instead of 7.3%).
  * *AAPL* — the latest quarter's diluted EPS is blank in Yahoo; it is back-filled from net income ÷ diluted shares.
  * Yahoo's `dividendYield` field is a percentage (0.32 = 0.32%); the pipeline computes yield from dividends paid.
  * *XOM* — files only the broad `Revenues` tag ("revenues and other income") for recent periods, so revenue is
    compared with a wider 5% band and an explanatory note; XOM's 10-K data is not in SEC companyfacts, so annual
    checks are SKIPped.

## Tests

```bash
pytest                 # offline, uses recorded real data in tests/fixtures
pytest --live          # also re-verifies a live basket against SEC + Nasdaq
python -m tests.record_fixtures   # refresh fixtures
```
